# 版本记录

## 1.0.3 · 2026-10-29

- 自动跳过纯表情、贴纸、图片占位和纯符号评论；带表情的文字评论原样保留。采集上限只计算文字评论，刷新恢复和导出也应用过滤。
- 视频工具的抖音/B站热评先过滤再选前三条；B站额外识别接口标注的自定义表情。
- 评论列表连续加载纯表情时继续扫描；旧缓存过滤后释放条数额度。

## 1.0.2 · 2026-10-28 · 公开发布版

- 视频工具保留抖音/B站采集、本地导出、飞书同步及百炼逐字稿功能。
- 公开版改为填写自己的飞书目标和授权；不预置个人资料库，不包含本机连接助手与自动迁移逻辑。
- 飞书连接测试同时检查字段和记录可读性，重复视频更新已有记录并保留完成稿。
- 切换飞书应用凭据会清除旧授权缓存；连接测试只复用当前 App ID 的授权。
- 评论上限100000条，默认从头采集到网页末尾。
- 评论增量保存、刷新恢复和去重；短暂加载不再提前结束，加载占位未进入视口时继续推进。
- 手动停止后立即刷新不复活任务，切换视频隔离旧评论。
- 保留米白、明黄与橙红界面，支持窄屏。

视频公开版的用户自有凭证写入流程需要各下载者完成自己的连接测试；发布验证不使用任何个人飞书或百炼凭证进行公开包端到端写入。

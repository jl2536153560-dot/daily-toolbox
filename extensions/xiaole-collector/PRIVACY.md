# 隐私说明

公开包不包含个人凭证、预置飞书资料库、真实采集记录或浏览器资料目录。

视频采集读取你正在使用的抖音/B站网页和相应平台返回的视频信息。选择飞书同步时，内容发送到你填写的飞书目标；选择百炼转写时，视频/音频地址或媒体发送给阿里百炼处理。扩展没有独立的开发者采集服务器。授权码、App Secret 和百炼 API Key 存在本机 Chrome 扩展存储中，请不要把带有个人设置的配置导出文件上传到公共仓库。

视频工具的 debugger 权限用于在受浏览器跨域约束的媒体读取场景中取回当前页面媒体；tabs、activeTab 和站点权限用于连接视频页面，storage 保存你的配置与任务，alarms 处理转写回写，declarativeNetRequestWithHostAccess 为平台媒体请求设置所需来源信息。公开版不申请 nativeMessaging，不连接作者本机的飞书 CLI，也不自动导入电脑里的设置。

私聊收集默认关闭。只有你主动填写目标会话/UID并启用后，才会读取配置的会话分享。首次启用建立历史基线，不自动收取此前的分享。浏览器登录态用于平台正常请求，不将平台 Cookie 或账号密码发送给飞书、百炼或开发者。

评论助手将已读取的公开主评论保存在当前页面内存和本机抖音网站的 IndexedDB，以支持同一标签页刷新后恢复。不同标签页与视频分别保存。关闭标签页不会自动续采；本地数据可通过 Chrome 网站设置清除。你主动导出的 CSV 由你管理。评论助手不会把正文上传到服务器，不自动点赞、回复、关注或发送消息。

详见评论安装目录中的 `PRIVACY.md`。网页结构、登录权限和平台返回内容会影响读取范围；任何总量、互动数或转写缺失都会保留缺失状态，不虚构补齐。

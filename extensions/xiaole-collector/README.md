# 小乐收集

把视频和评论整理成可以继续研究的内容素材。两款独立的 Chrome 扩展，使用米白、明黄与橙红界面。

| 工具 | 功能 | 版本 |
| --- | --- | --- |
| 视频采集 | 抖音、B站视频与主页作品；本地 JSON 导出；自己的飞书表格同步；百炼自动逐字稿 | 1.0.2 |
| 评论助手 | 抖音一级主评论；从头采集到底；刷新续采与去重；点赞/回复排序；CSV 导出 | 1.0.2 |

下载 GitHub 中的 ZIP 文件时，请使用文件页面上的下载按钮。源码下载也可以，直接加载下面 `extensions` 内相应目录。

## 安装到 Chrome

1. 解压下载包，保留解压后的目录。
2. 在 Chrome 地址栏输入 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的工具目录。
4. 两个工具分别加载一次，在工具栏拼图菜单中固定。刷新已打开的抖音或 B站网页。

这是本地加载版扩展，不是 Chrome 网上应用店的一键安装包。

## 视频采集

打开抖音或 B站的视频，点击扩展。可采集当前视频、主页作品、筛选作品，或从页面面板导出本地 JSON。

公开版没有预置任何人的飞书地址或 API Key。本地导出无需飞书授权；飞书同步和逐字稿需要你自己的配置：

1. 右键扩展图标，打开“选项”，选择多维表格授权码或飞书开放平台 App ID / Secret。
2. 填入你自己的授权及 Base Token、视频表 ID。`/base/` 链接可自动解析；`/wiki/` 知识库链接须另行填写其实际 Base Token。
3. 保存并测试连接。测试会读取字段与一条记录，不创建测试数据。缺少所需接口权限时会返回错误。
4. 如需逐字稿，填写自己的阿里百炼 API Key，选择可用模型，保存；采集时勾选“同步后转逐字稿”。调用会按你的百炼账户计费，完成后回写飞书。

视频写入你选定的表，达人资料单独写入“**小乐达人档案**”。重复采集按视频链接更新，已完成逐字稿不会因重复采集被清空。私聊收集默认关闭；只有主动配置并启用后才工作。

没有权限、登录失效或平台限制时，应按页面提示处理。不会保证绕过访问限制，也不会用标题冒充逐字稿。自动转写应在正式使用前听校。

## 评论助手

打开抖音单条视频并展开评论区，点击“自动采集”。默认选项为“**采集到底**”，上限 **100000 条**；也可选更小数量。

- 从评论区开头逐步滚动，保存已读取的主评论并去重。
- 慢加载和评论列表重建会等待；同一标签页刷新后自动续采。
- 后台或断网时挂起，回到页面或网络恢复后继续；登录/验证需要在网页完成后续采。
- 明确末尾，或底部稳定无新增后结束。长时间无进展会保存任务并重试。
- 手动停止后刷新不会自行重启；已完成任务也不会重复启动。
- 按点赞或回复排序导出 CSV。网页节点太多时保留网页顺序，CSV 仍应用所选排序。

仅收集网页实际加载的一级主评论，不含楼中楼。平台显示的总评论数可能包含回复，不等于本工具可采集的主评论数。刷新续采限同一次 Chrome 会话内的原标签页；关闭标签页或重启浏览器不会自动恢复旧任务。

## 源码与验证

```text
extensions/video-collector/       可直接加载，也是无构建的 JavaScript 源码
extensions/comment-assistant/     可直接加载的评论助手构建产物
src/comment-assistant/            TypeScript 源码、测试与构建脚本
tests/                           公开版视频默认配置与连接行为检查
downloads/                       独立下载包与组合包
```

```sh
node --test tests/*.test.cjs
cd src/comment-assistant
npm ci
npm test
npm run typecheck
npm run build
```

测试数据为合成数据。公开版不会读取作者电脑的本机连接助手，也不包含个人配置、浏览器资料目录或真实采集数据。详见 [隐私说明](PRIVACY.md)、[版本变化](CHANGELOG.md) 和 [来源与第三方说明](PROVENANCE.md)。

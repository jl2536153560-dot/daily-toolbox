# 隐私说明

「小乐收集 · 评论助手」在抖音网页版读取已显示的主评论正文、作者、互动数、发布时间、公开归属地以及当前视频标题和链接，用于本页排序和用户主动导出。

评论数据保存在当前页面内存及本机浏览器中抖音网站的 IndexedDB，用于同一标签页、同一视频刷新后续采和恢复导出。不同标签页、视频的数据分别保存，不混合；网站存储可在 Chrome 的网站设置中清除。关闭标签页或重启浏览器不会自动启动旧任务，已保存的数据仍占用本机网站存储。主动导出的 CSV 由用户管理。Chrome 扩展存储保存偏好和浏览器会话标识，不保存评论正文。

默认不自动滚动。用户点击自动采集后，从评论区开头逐步读取，等待加载期间保存进度；页面刷新后继续已开始的任务。默认采集到页面末尾，最多 100000 条，也可以主动选择更小数量上限。后台和断网时挂起，恢复后继续；登录或验证提示需要用户自行完成后续采。明确末尾或底部稳定无新增才结束，长时间无法加载会暂停重试。手动停止和已完成任务不会因刷新而自行重启。自动开关本身不会下载文件；用户选择“自动采集并导出”时，该任务在恢复并完成后会继续执行指定导出。

不读取 Cookie、账号密码或登录凭证；不调用私有评论接口、不拦截网络请求、不绕过访问限制，不自动点赞、回复、关注或发送消息，不向服务器上传评论。

权限：activeTab 和 scripting 用于用户点击图标后连接当前页面；storage 用于保存用户偏好；抖音主机权限仅供对应网页运行。未申请所有网站权限。

CSV 保留六列：排名、评论内容、作者、点赞数、回复数、发布时间。未知互动数留空；CSV 中疑似公式的字符串会加单引号以避免被表格执行。

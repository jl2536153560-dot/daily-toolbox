小乐收集 · 评论助手 1.0.3

安装：
1. Chrome 地址栏输入 chrome://extensions 。
2. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择本文件所在的 02-评论助手 目录（源码版也可以选择其中 dist）。
4. 打开抖音网页版视频并展开评论区。若页面已经打开过，请刷新一次。

使用：
• 点击橙红色「自动采集」，从评论区开头下滑读取，默认“采集到底（10万上限）”。
• 也可选择 100 / 200 / 500 / 1000 / 5000 / 10000 / 50000 条数量上限。采集中随时点击「停止采集」。
• 已读取的评论自动保存到本机网站存储。刷新同一标签页后自动恢复未完成任务，重新顺序扫描并去重，保留此前已读取的评论。
• 「打开评论区后自动采集」默认关闭。开启后会记住设置；每个新视频启动一次，不会自行下载。
• 页面顺序 / 点赞最多 / 回复最多：保留原评论卡片，直接调整页面顺序。
• 网页同时保留超过 2000 个可排序评论节点时保留页面顺序以避免卡顿；CSV 仍按所选方式排序，最多导出已收集的 100000 条。
• 导出菜单：导出已收集全部 / 按当前排序导出前 N 条 / 自动采集后导出前 N 条。
• 未能明确读取到的点赞数、回复数在 CSV 留空，明确显示的 0 保留。

采集边界：
仅支持抖音网页版的一级主评论，不包括楼中楼；不会自动打开未展开的评论面板。
目标是数量上限，不承诺平台全部评论；滚动一次可能多加载一批，导出前 N 条按目标截取。
短暂加载、评论列表刷新、后台和断网不会判定为完成。回到本页或网络恢复后继续；登录/验证须在网页完成后续采。
出现明确末尾，或到达底部并稳定30秒无新增才完成；长时间无进展先暂停并保留任务，页面恢复后重试。
手动停止后刷新不会自动重启；已完成的任务也不会重复启动。切换视频隔离数据，返回原视频可恢复未完成任务。
跨刷新恢复适用于当前Chrome会话内的原标签页；关闭标签页或重启浏览器不会自动恢复旧任务。清除网站存储会删除保存的评论。
不会点赞、回复、关注或发送消息；不需要 API Key，不上传评论。

兼容说明：
与旧「抖音评论排序器」一起启用可能重复显示两套排序按钮，建议在 Chrome 扩展页暂时关闭旧版。
评论助手与「小乐收集 · 视频逐字稿」可以同时使用。
抖音调整网页结构或限制访问时可能读不到内容；失败时「复制诊断」不包含评论正文。

验收说明：
已做离线解析/排序/去重/CSV/采集状态测试，以及 Chrome 中的合成页面交互测试。
合成页面用于检验慢加载、立即停止、刷新续采、切视频隔离和导出流程。实际可收集数量取决于网页已经加载的主评论，不能用总评论数（含回复）推算采集完整度。

自动跳过纯表情、贴纸、图片占位和纯符号评论；带表情的文字评论原样保留。采集上限只计算文字评论，刷新恢复和导出也应用过滤。
